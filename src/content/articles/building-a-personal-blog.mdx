## 开始之前

我很早就有写东西的习惯。小时候是日记本，大学是零散的便签，后来是手机里的备忘录。

那些文字散落在不同的地方，像一片片被风吹散的叶子，想回头找的时候，却总也找不全。有一段时间，我在学习和工作之间来回切换，脑子里有很多想法：关于设计，关于阅读，关于生活方式，也关于如何更认真地面对每天。

它们在脑子里打转，却没有一个安放的地方。我需要一个可以长期记录的地方，一个只属于我、我能掌控节奏的空间。

> 把走过的路，整理成可以再次抵达的文字。

这不是一个宣告，也不是一个项目计划。它更像是一封写给未来的信，提醒我不要忘记自己为什么出发。

## 为什么要写

写作最直接的价值，是迫使含糊的感受变得具体。一个念头只有经过整理、举例与删改，才会逐渐显出轮廓。

在这里，我希望记录四类内容：技术实践、项目复盘、设计与表达，以及少量生活随笔。它们不需要追逐更新频率，但要尽量完整、诚实、可回看。

### 让内容保持可迁移

文章使用 Markdown/MDX 保存，不依赖数据库。目录中的每一篇文章都是一个普通文本文件，可以被版本管理，也可以在未来迁移到别的系统。

```ts
export const writingRule = {
  publishWhen: '想法已经足够清楚',
  optimizeFor: ['长期可读', '真实复盘', '低维护成本'],
  avoid: ['追逐热点', '虚构成果'],
};
```

## 我想留下些什么

如果一篇文章能帮助未来的自己快速找回问题的上下文，它已经完成了最重要的任务。若它还能偶然帮助另一位读者，便是额外的幸运。

接下来，我会从正在经历的具体问题写起：一个设计决策为什么改变，一段代码为何重构，以及一个习惯如何慢慢形成。
