网站刚部署完成时，我在 Vercel 后台看到了“Pro 专业版试用 14 天”。第一反应是：14 天以后网站是不是就不能用了？如果必须付费，那有没有真正免费的方案？

## 14 天到期不等于网站到期

Vercel 提供 Hobby、Pro 和 Enterprise 三种计划。14 天只是 Pro 功能的试用期，不是账号或网站的有效期。

如果没有添加付款方式，试用结束后账号会降级到免费的 Hobby 计划；如果已经添加付款方式，则需要留意试用结束后的自动计费。因此，我需要确认的是团队设置中的 Billing 页面，而不是急着迁移网站。

## Hobby 对这个博客够不够

当前网站是 Astro 构建的静态博客，没有高频后端函数，也没有大量图片处理。Hobby 计划已经包含了我真正需要的能力：

- 从 GitHub 自动构建和部署；
- 免费的 `vercel.app` 访问地址；
- 自动 HTTPS；
- 自定义域名绑定；
- 面向个人项目的基础流量和构建额度。

个人博客的正常访问量很难触及这些额度。真正需要注意的是 Hobby 计划适用于个人、非商业用途。如果以后把网站变成商业产品，再考虑升级会更合理。

## 我最后怎么处理

我保留了当前部署，并确认 GitHub 仓库已经连接到 Vercel。试用期内可以继续使用 Pro 功能；到期后切换到 Hobby，也不会改变日常的文章发布流程。

这次问题让我意识到，看到“试用到期”时不能只看页面上的倒计时，还要分清试用的是增值功能，还是整个服务。对现在的我来说，先把内容写好，比提前购买超出需求的资源更重要。
